# Store Manager

## Problem Statement
Small stores need a simple way to manage product stock and create customer bills. Managing inventory manually can lead to incorrect stock counts, missing product details, and billing mistakes.

## Scope of the Project
This project is a command-line store billing and inventory management program. It allows the store owner to manage products, check available stock, add items to a cart, generate a bill, and update inventory after checkout.

## Target Users
- Small store owners
- Shopkeepers
- Students learning Python and basic inventory systems

## High-Level Features
- Add new products with product ID, name, price, and quantity
- Update existing product information
- Delete products from inventory
- Display the current inventory list
- Automatically convert product IDs to uppercase
- Validate product prices and quantities
- Add products to a customer cart
- Check stock availability before checkout
- Generate an itemized bill with total amount
- Reduce stock after checkout
- Save inventory changes in `inventory.json`
- Run automated tests for inventory, cart, and billing features
