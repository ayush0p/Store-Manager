# Store-Manager
Simple python based store management software, with inventory and checkout features 

#Features 
1- Convenient inventory system that allows to add/delete items 
2- Checkout system that takes products from inventory and makes a total bill

#Technology used 
1- Python 3
2- Microsoft Visual Studio Code 

#How to use 
1- Download the Store manager.py file
2- Open it IDE of Choice 
3- Alternately open terminal in the same directory as the file and run "python3 Store manager.py"
4- A welcome menu opens up, perform operations as needed
